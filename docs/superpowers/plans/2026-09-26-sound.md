# Sound Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Realistic synthesised engine, tyre and impact sounds in Drive, generative music and tunnel ambience in Studio
(spec: `docs/superpowers/specs/2026-09-26-sound-design.md`).

**Architecture:** Pure, Node-testable units (`engines.js`, `drivetrain.js`, `dsp/engineSynth.js`, `composer.js`) wrapped by
thin Web Audio classes (`AudioEngine`, `CarSound`, `impacts`, `StudioMusic`, `TunnelAmbience`). The engine runs in an
AudioWorklet bundled with Vite's `?worker&url`.

**Tech Stack:** Web Audio API (AudioWorklet, native nodes), Rapier collision events, Vitest.

## Global Constraints

- No audio files and no new dependencies.
- Audio starts only after a user gesture; suspended while the tab is hidden or muted; mute persisted in `localStorage`.
- Physics keeps pausing on dt = 0; audio must not break the Node tests (no Web Audio in pure modules).
- Italian UI copy, same glass HUD style.

### Task 1: Engine profiles — `src/audio/engines.js`, `tests/engines.test.js`

**Produces:** `ENGINES[carId]` → `{ label, cylinders: [{angle, bank}], banks, idle, redline, limiter, launch, revRate,
exhaust: {pipes: number[], muffler, reflection, brightness, level}, intake: {level, airbox}, mechanical: {level, modes,
valves}, turbo: null|{whistle:[lo,hi], level, bov}, hybrid: null|{whine, level}, gearWhine: {teeth, level},
gearbox: {gears: number[], type: 'dct'|'seamless'|'manual', shiftTime}, pops, starter: {type: 'motor'|'mguk', time},
squealHz, variability, gain }`; `engineFor(carId)`; `firingAngles(order, perBank)` helpers.

- [ ] Tests: every `CARS` id has a profile; angles in [0, 720) and unique; even-firing layouts have equal spacing;
  cross-plane V8 banks are uneven; gears strictly increasing, last ≥ 1.
- [ ] Implement, run `npx vitest run tests/engines.test.js`, commit.

### Task 2: Drivetrain — `src/audio/drivetrain.js`, `tests/drivetrain.test.js`

**Produces:** `new Drivetrain(profile)`, `.start()`, `.stop()`, `.update(input, dt)` with
`input = {speed, maxSpeed, reverseSpeed, throttle, handbrake, drifting, wheelspin, contact}` →
`{running, rpm, load, cut, gear, spool, overrun, starter, whineHz, whineAmp, gearHz, gearAmp, events}`
(`events`: `{type: 'crack'|'blip'|'bov'|'catch', size}`).

- [ ] Tests: start → cranking → idle within 3 s; full throttle 0→max speed upshifts through every gear; braking from
  max downshifts with `blip` events; stopped → idle rpm; no contact + throttle → limiter bounce (cut toggles); reverse
  gives gear −1; stop → rpm 0.
- [ ] Implement, test, commit.

### Task 3: Engine DSP — `src/audio/dsp/engineSynth.js`, `tests/engineSynth.test.js`

**Produces:** `new EngineSynth(sampleRate, seed)`, `.setProfile(p)`, `.set(params)`, `.trigger(event)`,
`.process(left, right)`; params: drivetrain output + `{squeal, squealHz, scrub, roll, exhaustOpen, gain}`.

- [ ] Tests (render in Node): finite and |x| ≤ 1; energy at firing frequency ≫ off-harmonic; cross-plane V8 has more
  half-order energy than flat-plane; silence when off.
- [ ] Implement; render WAVs + spectrograms of a scripted drive per car in the scratchpad; tune levels; commit.
